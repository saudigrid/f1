# بيانات الموقع

## حقيقية ✓

`drivers.json` · `teams.json` · `races.json` · `standings.json`

تُسحب من واجهة Jolpica المفتوحة (متوافقة مع Ergast، بلا مفتاح) عبر:

```bash
npm run sync              # الموسم الحالي
npm run sync -- 2025      # موسم بعينه
```

شغّلها كلما أردت تحديث النتائج — بعد كل سباق مثلاً. الكتابة كاملة في كل مرة،
ولا تُلمس الأخبار.

الأسماء تُعرَّب في `src/lib/data/arabic-names.ts`. أي معرّف جديد (سائق ينضم،
فريق يتغيّر اسمه) يظهر بالإنجليزية **مع تحذير في مخرجات المزامنة** — أضف سطراً
هناك وأعد التشغيل.

## تجريبية ⚠

`articles.json`

أخبار توضيحية كتبناها لملء الواجهة أثناء التطوير. **ليست أخباراً حقيقية**،
وبعض وقائعها لا تطابق الترتيب الحقيقي أعلاه. تُستبدل بالكامل بأول تشغيل ناجح
لخط الأتمتة:

```bash
npm run pipeline
```

## في الإنتاج

عند ضبط متغيّرات Supabase يتجاهل الموقع هذا المجلد كلياً ويقرأ من قاعدة
البيانات — انظر `src/lib/data/repository.ts`.
